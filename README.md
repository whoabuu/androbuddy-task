ShopSphere: Home & Product Browsing (FE-1)

The browsing slice of a fictional e-commerce storefront: home page, paginated product listing and product detail. Built for the Andro Buddy Technologies FE-1 assignment.

Data comes from the Fake Store API; there is no backend. The visual style (white canvas, grey image tiles, pill buttons, bold italic wordmark) is inspired by Nike's storefront. No Nike code, logos or assets are used.

Tech stack

React + TypeScript (Vite) · React Router · Axios · Tailwind CSS v4

Getting started
bash
npm install
npm run dev        # http://localhost:5173
npm run build      # typecheck + production build
npm run preview    # serve the production build

Use a current Node LTS (20.19+ or 22.12+).
